### 几个高价值发现（后续处理时优先看这几条）
- **P0**：`android/key.properties`（明文 storePassword/keyPassword=dc16@sms）与 `android/app/key/sms.keystore` 已被 git 跟踪（`git ls-files` 确认），签名密钥随仓库分发。
- 分页线性退化：Kotlin `querySms` 里 `maxRows = offset + limit`，每页都从头重读并重排 `out.sortedWith(ROW_ORDER)`，翻到第 N 页代价 O(N²)。
- 导出静默丢数据：`sms_data_service.exportAll()` 走 `queryAll()`，丢弃 `partial`/`warnings`；且整个 CSV 用单个 StringBuffer 在内存拼完再同步写盘。
- `android/gradle.properties` 里 `kotlin.incremental=false`（某开发者 C:/D: 跨盘问题）与 `-Xmx8G` 已提交，污染 Linux CI（runner 仅 7GB 内存）。
