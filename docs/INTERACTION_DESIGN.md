## 1. 状态模型（全局）

```
                    ┌─────────────┐
         启动 ────► │  Booting    │
                    └──────┬──────┘
                           ▼
              hasRead? / query
                           │
         ┌─────────────────┼─────────────────┐
         ▼                 ▼                 ▼
   ┌──────────┐     ┌──────────┐      ┌───────────┐
   │ NeedPerm │     │  Empty   │      │   List    │
   └────┬─────┘     └────┬─────┘      └─────┬─────┘
        │ 申请成功        │ 有数据            │ 筛选/多选/删除
        └────────► List ◄─┴──────────────────┘
                     │
                     ▼
              ┌──────────────┐
              │ SelectMode   │（多选子状态）
              └──────────────┘
```

| 状态 | 进入条件 | 主界面 |
|------|----------|--------|
| NeedPerm | `!hasRead` 且非默认，或 query 返回 permission | 锁图标 + 申请权限 |
| Empty | query 成功且 0 条 | 空态 + 重新加载 |
| List | query 成功且 ≥1 条 | 分组列表 |
| SelectMode | 长按/菜单进入 | 顶栏已选 n + 底栏导出/删除 |

**原则**
- 权限结果**不缓存**：每次 `_load()` 都重新 `hasReadSms`。
- 读：`hasRead`；删：`isDefault`。二者独立。

## 2. 初始状态（冷启动）

| 步骤 | 行为 | UI |
|------|------|-----|
| 1 | 建主题、注入 `SmsRepository` | 闪屏/主题 |
| 2 | `_load()`：`hasReadSms` + `querySms` | 顶部标题显示计数（先 0/「加载中」） |
| 3a | 无读权限且非默认 | **NeedPerm**：锁 + 「申请短信权限」 |
| 3b | 有权限，0 条 | **Empty**：没有短信 + 「重新加载」 |
| 3c | 有权限，N 条 | **List**：分组卡片 |

**不弹系统权限框**（冷启动不打扰）；只在用户点「申请短信权限」时 `requestReadSms`。

## 3. 权限与角色操作

### 3.1 申请短信权限（NeedPerm / 设置页）

```
点「申请短信权限」
  → requestReadSms()          // 系统弹窗
  → 结束后 _load()
       ├─ hasRead → List / Empty
       └─ 仍无 → 保持 NeedPerm，文案提示可去系统设置
```

| 系统结果 | 产品行为 |
|----------|----------|
| 允许 | 刷新列表；Toast「已可读取短信」 |
| 拒绝 | 仍 NeedPerm；次按钮「打开应用设置」 |
| 长期拒绝 | 同上，不循环弹窗 |

### 3.2 设为默认短信（删除前置）

```
删除时 isDefault != true
  → 弹层：「删除需要本应用为默认短信」
       ├─ [去设为默认] → setDefaultSms()  // RoleManager 弹窗
       └─ [取消]

setDefaultSms 返回
  ├─ had  → 已是默认，继续删
  ├─ no   → 用户去系统确认；返回后 _load() + 重试删除
  └─ error→ Toast 失败，可「打开默认应用设置」
```

### 3.3 掉默认 / 系统收权

| 现象 | 处理 |
|------|------|
| 进程被杀 | 冷启动走 §2，不报错 |
| AppOps=ignore | `hasRead=false` → NeedPerm |
| 误报已授权 | 以 AppOps 为准，不短路 request() |

| 步骤 | 行为 |
|------|------|

| 确认 | `deleteSmsBatch` → toast 成功/失败 → `_load()` |
| 非默认 | 弹层转「去设为默认」 |

| 条件 | 按钮 | 行为 |
|------|------|------|
| NeedPerm | 申请短信权限 | §3.1 |

| 筛选无果 | 清除筛选 | 重置 filter → 列表 |

## 5. 查询 / 删除逻辑（与设计文档一致）

```
_load()
  hasRead = hasReadSms()          // checkSelf + AppOps
  if (!hasRead && !isDefault) → NeedPerm
  else querySms(address?)       // 多 URI 合并
       → List / Empty / 错误提示

delete(ids)
  if (!isDefault) → 引导设默认
  else deleteSmsBatch(ids)      // chunk 900
       → _load()
```

- 客户端过滤：关键词 / 日期 / 同号 / 同卡（不重复打库）。
- `id` 一律用 `_id`，不用下标。

## 6. 设置页优化（在现有分组列表上加强）

### 6.1 信息架构（增强）

```
设置
├─ 外观
│   ├─ 主题色          [色值/预设]  ›
│   └─ 深色模式        跟随系统     ›
├─ 权限
│   ├─ 短信权限        ● 已授予/未授予  ›  [子页]
│   └─ 默认短信应用    ● 本应用/系统短信 ›  [设为默认/打开设置]
├─ 数据
│   ├─ 导出全部 CSV
│   └─ 清理预览        （可选，v2：统计将删除多少）
└─ 关于
    ├─ 版本 2.0.0
    ├─ 隐私说明
    └─ 源码许可 / 反馈
```

### 6.2 交互优化点

| 项 | 现状 | 建议 |
|----|------|------|
| 权限状态 | 静态「已授予」 | 进入页面**实时** `hasReadSms` / `isDefaultSms`；红/绿点 + 右侧值 |
| 短信权限行 | 点进说明页 | 行内右侧「去开启」按钮（未授予时）；已授予则只读 |
| 默认短信行 | toast | 未默认：主按钮「设为默认」；已默认：「打开系统设置」 |
| 一键修复 | 无 | 权限页底部「自动检查并修复」：request → setDefault → 回列表 |
| 导出 | toast | 真导出 CSV + 分享；显示条数 |
| 存储占用 | 无 | （可选）显示导出目录/清空 |
| 关于 | 版本号 | 加「开源许可」「问题反馈」 |
| 危险操作 | 无 | 「重置本地隐藏列表」（若做移出列表） |

### 6.3 权限子页（建议）

```
短信权限
├─ 读取短信     ● 已授予 / AppOps 正常     [刷新状态]
├─ 默认短信     ● 本应用                 [去系统设置]
└─ 说明：掉默认后系统可能收回权限…
   [申请短信权限]  [打开应用设置]
```
