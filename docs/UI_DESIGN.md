# 短信清理 2.0 — 界面设计说明

> 适用项目：`/Users/fang/StudioProjects/sms`  
> 本文是视觉/交互规格；实现按本文落地，改动需回写本文件。

## 1. 设计原则

1. **清理是主任务**：打开即见短信列表，删除路径不超过 2 步。
2. **危险操作可预期**：删除永远有确认与进度，可取消；不弹多层套娃对话框。
3. **权限状态可视化**：权限 / 默认短信应用做成设置页一等公民，空态可一键修复。
4. **安静的工具感**：少色、高对比、大点按区；列表信息层级靠字重与留白，不靠花哨图标。

## 2. 色彩

| 角色 | 浅色 | 深色 | 用途 |
|------|------|------|------|
| Primary | `#2BAE67` | `#5BD98A` | 主按钮、选中、强调 |
| On Primary | `#FFFFFF` | `#0B2A17` | 主按钮文字 |
| Surface | `#F7FAF8` | `#0F1411` | 页面背景 |
| Surface Container | `#FFFFFF` | `#1A221D` | 卡片、弹层 |
| Outline | `#D5DED8` | `#3A4640` | 分割、控件描边 |
| Error | `#C62828` | `#FF8A80` | 删除、失败 |
| Error Container | `#FDECEC` | `#3A1B1B` | 删除确认底 |
| On Surface | `#15211A` | `#E3ECE6` | 正文 |
| On Surface Var | `#5C6B63` | `#A8B5AE` | 次要文字（号码、时间） |

- 强调色只用于「可点主操作 / 当前选中 / 过滤已激活」。
- 列表卡片不使用阴影，用 1px 描边或背景色差。

## 3. 字体与字阶

字体：系统默认（`PingFang SC` / `Roboto`），不引入自定义字体。

| 级别 | 尺寸 | 字重 | 用途 |
|------|------|------|------|
| Display | 28 | w700 | 空态标题、设置页大标题 |
| Title | 20 | w700 | AppBar 标题、筛选面板标题 |
| Body | 16 | w400 | 短信正文 |
| Body Medium | 16 | w500 | 按钮、菜单项 |
| Label | 14 | w500 | Chip、字段标签 |
| Caption | 12 | w400 | 时间、号码、计数 |

行高：正文 1.45，列表项最大 3 行截断 + 展开。

## 4. 布局与间距

- 基准 4px；常用间距 8 / 12 / 16 / 24。
- 页边距 16；列表卡片间距 8。
- AppBar 高 56（不含状态栏）；列表项最小高 88。
- 所有可点区域 ≥ 48×48。
- 底部主操作区（多选栏、FAB）距底 ≥ 16 + 安全区。

## 5. 信息架构

```
首页（列表）
├─ AppBar：标题（n 条） / 搜索 / 筛选 / 菜单
├─ 筛选 Chip 行（有筛选时才显示）
├─ 列表（按日分组，最新在上）
├─ FAB：删除当前列表
└─ 多选模式：顶栏「已选 n / 全选 / 关闭」+ 底栏「导出选中 / 删除选中」

菜单（更多）
├─ 导出全部 CSV
├─ 申请短信权限 / 权限状态
├─ 设置
└─ 关于

列表项动作（点开/长按出 ActionSheet）
├─ 同号短信（按 address 过滤整列表）
├─ 同卡短信（按 SIM 过滤）
├─ 复制号码 / 复制正文
├─ 快速删除（单条，成功后轻提示，不弹确认）
└─ 移出列表（仅本地隐藏，不删系统短信）

设置页
├─ 外观
│   ├─ 主题色（预设色盘 + 实时预览）
│   └─ 深色模式（跟随系统 / 浅色 / 深色）
├─ 权限与应用
│   ├─ 短信权限（状态 + 申请/去设置）
│   ├─ 默认短信应用（状态 + 去设置）
│   └─ 存储权限（导出需要时才出现）
├─ 数据
│   └─ 导出全部 CSV
└─ 关于（版本、隐私说明、开源许可）

空态 / 权限态

└─ 查询失败（主按钮：重试）
```

## 6. 核心界面规格

### 6.1 首页 · 短信列表

- **AppBar（仅 3 个入口，不拆搜索/筛选）**：
  1. **搜索/筛选**（🔍）：一个入口打开「搜索 / 筛选」Sheet——关键词即时过滤正文与号码，可叠加日期、类型；不是两个按钮。
  2. **设置**（⚙）：进入设置页。
  3. **更多**（⋯）：导出 CSV、多选、申请权限。
- **筛选行**：已启用时显示 Chip（日期 / 关键词 / 号码 / SIM / 同号），Chip 可单个删除；「清除全部」在行尾。
- **列表卡片**：
  - 左：正文 3 行截断
  - 右下：时间（今天只显时:分，更早显 MM-DD 或 YYYY-MM-DD）
  - 副行：SIM 徽章 + 号码（号码 ellipsis）
  - 交互：**单击**出动作 Sheet；**长按**进多选；**左滑**露出「快速删除」
- **FAB**：垃圾桶；点击弹确认「删除列表中 n 条？」。

### 6.1b 列表项动作 Sheet（核心入口）

| 动作 | 说明 |
|------|------|
| 同号短信 | 以该 address 为筛选，整列表只看这个号码；Chip 显示「同号 138****」 |
| 同卡短信 | 按 SIM 槽过滤 |
| 复制号码 / 复制正文 | 成功 toast |
| **快速删除** | 删除该条 **不弹确认**，行内移除 + 底部 toast「已删除，撤销」 |
| 移出列表 | 仅隐藏本地列表，不删系统短信 |

- 快速删除：危险项文案用 Error 色，但不做成整页红。
- 「撤销」可选：5s 内撤销则不真正调平台删除（或删除后仅提示不可撤销，v1 先不做强撤销）。

### 6.2 多选模式

- 顶栏变为：关闭 · 已选 n · 全选
- 列表项左侧 Checkbox，点整行切换
- 底部操作栏：导出选中 | 删除选中（危险色）
- 空选时删除禁用

### 6.3 搜索 / 筛选（同一入口、同一弹层）

- 顶栏只有一个 🔍，不把「搜索」「筛选」拆成两个按钮。
- 弹层内：**关键词**（即时过滤正文+号码）+ 开始/结束日期 + 类型（全部/收件箱/已发送）。
- 与列表内「同号短信 / 同卡短信」生成的 Chip 可叠加。
- 主按钮「完成」，次按钮「重置」。

### 6.4 确认删除（底部弹层，非系统对话框）

- 标题：删除短信？
- 说明：「将删除 n 条，不可恢复」
- 进行中：进度条 + 「已完成 x / n」+ 取消
- 结束：成功 toast / 失败「成功 x，失败 y」

### 6.5 设置（重设计）

不要用「大按钮堆卡片」，改为**系统设置式分组列表**（分组标题 + 行 + 右侧值/开关/箭头）。

```
设置
┌─ 外观 ─────────────────────────────┐
│ 主题色          [色点 ●]  ›        │  ← 进入主题色选择
│ 深色模式        跟随系统  ›        │  ← 跟随系统/浅色/深色
└────────────────────────────────────┘
┌─ 权限 ─────────────────────────────┐
│ 短信权限        已授予    ›        │  ← 未授予时右侧「未授予」+行可点申请
│ 默认短信应用    短信清理  ›        │  ← 非默认时「去设置」
└────────────────────────────────────┘
┌─ 数据 ─────────────────────────────┐
│ 导出短信 CSV    导出      ›        │
└────────────────────────────────────┘
┌─ 关于 ─────────────────────────────┐
│ 版本            2.0.0
│ 隐私说明        ›
└────────────────────────────────────┘
```

**主题色选择页/弹层**
- 预设色盘（8 色圆点，当前色打勾）：绿 `#2BAE67`、蓝、紫、橙、红、青、粉、深灰
- 选中即时换肤（App 主色 / 主按钮 / Chip / 开关）
- 说明一行：「影响主按钮、选中态与强调色」

**权限行交互**
- 已授予：绿色点 +「已授予」，点击进说明
- 未授予：橙色点 +「未授予」，主按钮文案「申请短信权限」（调系统弹窗）
- 默认短信非本应用：提示删除会受限，一键「去设置」

### 6.6 空态

- 插图位（线性图标即可）+ 一句话 + 一个主按钮
- 三态：没有短信 / 需要权限（申请权限）/ 加载失败（重试）

### 6.7 功能保留对照（必做）

| 1.x 功能 | 2.0 落点 |
|----------|----------|
| 同号短信 | 动作 Sheet「同号短信」+ Chip |
| 同卡短信 | 动作 Sheet「同卡短信」+ Chip |
| 快速删除 | 左滑删除 / Sheet「快速删除」 |
| 导出 CSV | 菜单、多选底栏、设置页 |
| 申请权限 | 空态、设置页权限行 |
| 默认短信 | 设置页、空态引导 |
| 自定义主题色 | 设置 → 主题色（新增） |
| 搜索 / 日期筛选 | 搜索栏 + FilterSheet |

## 8. 动效

- 列表增删：200ms fade/slide，不抢焦点。
- 多选进入：顶栏与列表 150ms 交叉淡入。
- 弹层：底部 sheet 上滑 220ms，背景遮罩 0.32。
- 列表项删除：播放滑出后移除（若成本高可直接刷新）。

## 9. 可访问性

- 动态字体：支持系统字号缩放到 1.3x。
- 深色模式：完整 token 表。
- 图标按钮均带 tooltip / 语义标签。
- 危险操作不单靠红色，文案写明后果。

## 10. 与旧版差异（便于对照）

| 项 | 1.x | 2.0 |
|----|-----|-----|
| 筛选 | 菜单/日期弹窗 | 底部 FilterSheet + Chip |
| 多选 | 有 | 保留并强化底部操作栏 |
| 删除 | CupertinoActionSheet 多层 | 单一 ConfirmSheet + 进度 |
| 设置 | Popup 菜单直接动作 | 独立设置页，状态可见 |
| 列表 | 纯 ListTile | 分组卡片 + 时间策略 |
| 权限 | toast 驱动 | 设置页状态卡 + 空态修复 |
